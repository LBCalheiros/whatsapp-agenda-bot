# whatsapp-agenda-bot

I am developing a WhatsApp bot that allows clients to automatically book and manage their appointments. Clients will receive appointment reminders and can reschedule or contact a professional if needed.

## Status

Work in progress. This is a personal/study project, not production-ready yet.

## Stack

Next.js (App Router) + TypeScript, PostgreSQL (`pg` + `node-pg-migrate`), WhatsApp Cloud API.

## Running locally

```bash
npm install
npm run services:up
npm run migration:up
npm run dev
```
